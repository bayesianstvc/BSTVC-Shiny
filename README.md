# BSTVC-Shiny
BSTVC-Shiny is an interactive web application for Bayesian spatiotemporally varying coefficient analysis. It provides a browser-based workflow for model fitting, visualization, interpretation, and prediction, enabling users to explore spatial and temporal heterogeneity without complex programming or local software installation, directly in R.
